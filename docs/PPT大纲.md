## P2 · 一句话讲清楚（20 秒）

```
全市场 5000+ 股票
      │
      ▼
  今天大盘怎么样？（趋势评分）
      │
      ▼
  哪个行业最强？（RS + 盈利代理 → 行业轮动）
      │
      ▼
  行业内买哪只？（动量 + 质量排序）
      │
      ▼
  每只买多少？（权重 → 股数 → 风控）
      │
      ▼
  最终订单（先卖后买，对比现有仓位做差）
```

> "每 3 天全市场重新排名一次，谁排前面买谁，掉出就卖。"

## P3 · 五层架构（大图，40 秒）

```
⑤ 约束层   硬风控（现金≥5%，单股≤25%，整手检查）    ← LLM不可绕过
④ LLM 层   4个Agent做判断（市场/行业/个股/分配）      ← 在线可选，挂了降级
③ 记忆层   历史经验+知识库（越跑越聪明）              ← 向量检索，不靠LLM总结
② 规则层   趋势评分·RS排名·K线特征·情绪快照           ← 始终运行
① 工具层   行情·指标·券商·LangChain Tools             ← 基础设施
```

**数据流**：①出数据 → ②算特征 → ③出经验 → ④做判断 → ⑤保安全

> "和传统 Agent 最大的区别：我们把感知层拆成了工具层和规则层，多了硬风控层。规则不是替代 AI，而是武装 AI——先把方向、排名、特征全算好，AI 拿着全套情报做判断，而不是对着原始行情瞎猜。"

---

## P4 · 记忆怎么让 Agent 越跑越聪明（30 秒）

```
决策时：
  当前K线形态 → 4维向量 → 搜历史 → "上次类似行情选bullish赚了+5.2%"
  → 拼成一段话注入LLM prompt

回填时：
  下个再平衡日 → 算区间超额 → 写回 active_return
  → 记忆从"输入"变成"输入+结果"
```

- 门控：<3 条回填记录不注入，防止噪音误导（实测发现 1-2 条会让 LLM 反向出错）
- 同机制偏置：牛市只搜牛市经验

> "不靠 AI 自己总结——总结会丢信息。我们直接用向量搜相似行情，把历史的输入和结果原文拼接，精确。"

## P5 · 规则怎么武装 LLM（30 秒）

```
LLM 拿到的不是"今天收盘 3.25 元，你判断一下"

而是：
  趋势评分 = 0.35（偏 bullish）
  RS 排名：通信第1，电子第2，电力设备第3
  K线特征：RSI=52, 波动率=2.1%, 广度=72%
  情绪：72%的股票在SMA20上方，偏乐观
  经验：上次类似K线你选bullish赚了+5.2%
  知识：电子行业对政策利率与半导体周期高度敏感

→ 拿着这些情报，你再判断
```

> "规则层的活是算数字，LLM 层的活是在数字基础上做语义判断。各干各的。"

## P6 · 决策路由（大图，20 秒）

```
START → Universe → Market Regime → Sector → Stock → Allocator → END
         (加载       (趋势评分)     (行业     (个股     (权重→
          预筛)                     轮动)     排序)     风控→下单)

唯一岔路口：Universe 之后，候选池为空 → 直接 END（不交易）
其余全链一条路走到头
```

> "路由很简单——单次决策一条直线，唯一的 if 是'今天还有能买的吗'。"

## P7 · 连续决策与仓位调整（20 秒）

```
每 3 天一次再平衡 → 跑完整选股链路 → 生成全新目标仓位

对比现有持仓：
  target > current → 买（加仓）
  target < current → 卖（降权/被踢出）
  target = current → 不动

先卖后买，腾钱再下单
```

> "没有单独的卖出信号——排名掉了就减，被踢出候选池就清。每次重新排名，就像 GPS 重新规划路线。"

## P9 · 总结（20 秒）

**做了什么**：一个五层耦合的多标的选股交易 Agent，能自动从全市场选行业、选个股、下单

**三个亮点**：
1. 规则+LLM 耦合 —— 规则算数字武装 AI，AI 做判断
2. 经验学习闭环 —— 每次决策记录+回填，越跑越聪明
3. 硬风控把关 —— LLM 说"我想买"，约束层说"你只能买这么多"

**局限与后续**：924 窗口极端、V 反天然滞后、候选池偏窄 → 扩池 + 滚动验证

> "规则层是情报员，记忆层是档案室，LLM 层是分析师，约束层是合规官——各有分工，耦合驱动。"

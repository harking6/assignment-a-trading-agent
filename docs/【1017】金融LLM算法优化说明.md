# 队友交付：金融 LLM 量化策略优化与展示结果

## 一句话说明

本次把策略从“因子选股 + 直接配权”的可运行原型，升级为“稳健多因子选股 + 信号感知风险预算 + 金融 LLM 五偏差结构审计”的可展示回测链路；重点是让收益、风险、成本和模型决策边界能在同一份报告中被追溯。

## 优化内容

### 1. 稳健多因子评分

```text
Momentum = RobustZ(0.15 × R1d + 0.35 × R5d + 0.50 × R20d)
FactorScore = 0.45 × Momentum + 0.35 × Trend + 0.20 × LowVolatility
```

- `RobustZ` 使用中位数/MAD 标准化，并截断在 `[-3.5, 3.5]`；避免小股票池里单只异常涨跌把均值和标准差拉偏。
- 输出可展示的动量、趋势、低波动因子贡献和综合因子分数。

### 2. 信号感知风险预算

```text
w_final = (1 - λ) × w_signal + λ × normalize(1 / σ20)
RC_i = w_i × σ_i / Σ(w_j × σ_j)
```

- 默认 `λ=0.65`，可由 `risk_parity_strength` 配置；`0` 为旧版信号权重，`1` 为纯逆波动权重。
- 不推翻 LLM/因子信号，而是在配权层降低高波动标的的风险集中。
- 输出风险调整权重、单股风险贡献、有效持仓数和组合波动代理。

### 3. 金融 LLM 结构有效性审计（Five Sins）

| 偏差 | 已实现的工程约束 | 展示字段 |
| --- | --- | --- |
| 前瞻偏差 | 经验召回仅使用 `outcome_day < decision_day` 的历史结果 | `look_ahead` |
| 幸存者偏差 | 校验动态股票池的 `as_of` 快照时间；不可验证时明确标注 | `survivorship` |
| 叙事偏差 | 每个目标持仓必须来自当前带因子证据的候选集 | `narrative` |
| 目标偏差 | 空仓/no-trade 是合法的 LLM 决策，不会回退成默认满仓 | `objective` |
| 成本偏差 | 同时报告手续费、换手、LLM 调用数及推理时延 | `cost` |

审计结果位于 `engine.report()["bias_audit"]`；单步接口还提供 `to_dict()["bias_audit"]`，可直接用于前端做“五项状态卡片”。

## 完整验证结果

### 设置

- 数据：项目内确定性合成市场，保证基线与优化组输入完全一致。
- 周期：4 个市场情景 × 每情景 504 个交易日（约两年）× 2 个配权版本，共 8 组完整运行。
- 调仓：每 5 个交易日；6 个候选标的；最多 4 个持仓。
- 摩擦：默认手续费率 `0.12%`，滑点 `2 bps`。
- 对照：`λ=0`（信号权重基线）vs `λ=0.65`（信号 + 逆波动风险预算）。

### 审计结果

全部 8 组中，前瞻、叙事、目标和成本检查均为 `pass`。幸存者偏差为 `not_applicable`：原因是验证采用静态合成股票池，不能证明真实市场中包含退市标的；这项限制被显式保留，而非误报为通过。

## 展示建议

1. 组合页面：股票表增加“因子得分 / 风险调整权重 / 风险贡献”三列。
2. 风险面板：显示有效持仓数、组合波动代理、手续费与累计换手。
3. LLM 面板：五张偏差审计状态卡；对幸存者项显示“需要逐日历史股票池验证”。
4. 结果页：展示上表，并注明“合成市场工程验证，不构成真实市场收益承诺”。

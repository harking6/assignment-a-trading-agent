# 记忆层短窗 A–E 五组消融实验结果

## 一、结论摘要

本轮实验完成了量化多智能体系统记忆层的 A–E 五组消融验证。结果表明，经验记忆的召回、质量筛选、时效加权和有效样本量门控均已在真实 LLM 调用与历史行情回测链路中正常执行。

- B（现有基线）、C（质量门控）、D（质量加时效）均在测试期内完成 2 次经验注入；每次均召回 3 条已结算历史经验。
- E（完整方案）在两次召回中均因有效样本量 `Neff` 分别为 1.50、1.34，低于阈值 2.00，主动停止经验注入。这验证了完整方案能够拒绝高度同质、证据不足的历史样本，避免“少量经验被当作可靠规律”。
- D、E 的单次短窗超额收益分别为 3.0049% 和 3.0284%，高于 A–C；但本轮每组仅运行 1 次，且 E 实际未注入经验，不能据此将收益差异直接归因于完整记忆层。该结果应作为链路可用性与安全门控验证，不作为最终收益结论。

## 二、实验设置

| 项目 | 配置 |
|---|---|
| 实验类型 | 多智能体量化选股系统的记忆层消融实验 |
| 数据源 | AkShare 历史行情 |
| 预热区间 | 2024-01-22 至 2024-02-05 |
| 测试区间 | 2024-02-05 至 2024-02-16 |
| 初始资金 | 1,000,000 元 |
| 动态股票池 | 4 只候选股票，2 个行业，每行业 1 只股票 |
| 调仓频率 | 每 3 个交易日一次 |
| 最大持仓数 | 2 只 |
| 每组重复次数 | 1 次 |
| 模型模式 | LLM 多智能体模式 |

预热区间仅用于形成已结算的历史决策与收益记录；测试区间的行情价格不会写入预热记忆，因此实验满足时间顺序上的反向泄漏约束。

## 三、消融方案说明

| 方案 | 记忆策略 | 目的 |
|---|---|---|
| A 无经验 | 关闭经验记忆 | 作为无历史经验的对照组 |
| B 现有基线 | 传统相似度召回 | 对照改进前的经验调用方式 |
| C 质量门控 | 仅召回质量达标样本 | 验证样本质量筛选效果 |
| D 质量加时效 | 质量、相似度、市场状态与近期性联合排序 | 验证近期同类经验的优先级 |
| E 完整方案 | D + 有效样本量 `Neff ≥ 2` 才允许注入 | 防止少量高度相似经验造成过度置信 |

## 五、记忆召回与门控证据

| 方案 | 测试期召回情况 | 是否注入经验 | 解释 |
|---|---|---|---|
| A 无经验 | 已关闭 | 否 | 对照组，不调用经验层 |
| B 现有基线 | 2 次；每次 3 条样本；`Neff=2.79/2.83` | 是 | 基线相似度召回正常工作 |
| C 质量门控 | 2 次；每次 3 条样本；`Neff=1.41/1.35` | 是 | 质量合格样本可进入提示词上下文 |
| D 质量加时效 | 2 次；每次 3 条样本；`Neff=1.50/1.34` | 是 | 加入近期性后的经验排序可正常注入 |
| E 完整方案 | 2 次；每次 3 条样本；`Neff=1.50/1.34` | 否 | 样本集中度过高，未达到 `Neff ≥ 2` 的最低证据要求 |

`Neff`（有效样本量）用于衡量多条召回经验是否真正提供独立信息。虽然 E 组召回到了 3 条记录，但它们的相似度权重过于集中，相当于不足 2 条独立经验；因此系统选择不向 LLM 注入经验提示。这是完整方案的预期安全行为，而非故障。

## 六、结果解读与可汇报表述

本轮结果证明：记忆层已从“存储历史决策”升级为可验证的“决策—结果回填—相似经验召回—质量/时效/有效样本量筛选—提示词注入”闭环。B 至 D 组的注入记录说明经验层能够稳定接入多智能体决策流程；E 组的拦截记录说明系统不会在证据不足时盲目沿用历史经验。

建议在答辩或项目汇报中采用以下表述：

> 我们在短窗真实行情回测中完成了五组记忆层消融验证。实验确认，质量门控、时效加权与有效样本量约束能够在多智能体决策中稳定生效；完整方案会在历史样本同质性过高时主动拒绝注入经验，降低经验偏置和信息泄漏风险。当前短窗结果用于证明工程链路与风控约束有效，后续将通过多市场阶段、多次重复回测评估其稳健收益贡献。

不建议将本轮 D、E 的较高单次超额收益直接写成“完整记忆层显著提升收益”，原因是：

1. 每组仅运行 1 次，LLM 输出与动态股票池均存在随机性；
2. 测试窗口较短，Sharpe 和收益指标容易受单段行情影响；
3. E 组的有效样本量门控未满足阈值，实际没有注入经验，不能将该组收益归因于经验上下文。

## 七、下一步实验建议

下一轮应使用更长、更多样的预热历史，使完整方案在部分场景下达到 `Neff ≥ 2` 并真正注入经验；随后在春节反弹、1 月杀跌、震荡阴跌、924 急涨等不同市场阶段分别进行多次重复回测。建议以各阶段的中位数超额收益、Sharpe、最大回撤和换手为核心指标，再判断记忆层是否带来稳定的边际收益。

# 多因子风险预算：长周期滚动验证

## 展示亮点

本次优化把原本的“选中高分股后按信号直接配权”，扩展为一条可解释的量化组合构建链路：

```text
1/5/20 日动量 + 趋势 + 低波动因子
        ↓（Median/MAD 稳健标准化，限制离群值）
横截面综合评分与候选股选择
        ↓（信号权重与逆波动权重混合）
风险预算配权 → 下单目标仓位
        ↓
展示：因子暴露、风险调整权重、单股风险贡献、有效持仓数、组合波动代理
```

### 1. 稳健多因子评分

每只股票的综合因子为：

```text
FactorScore = 0.45 × Momentum + 0.35 × Trend + 0.20 × LowVolatility
Momentum = RobustZ(0.15 × R1d + 0.35 × R5d + 0.50 × R20d)
```

其中 `RobustZ` 用中位数与 MAD（median absolute deviation）缩放并截断到 `[-3.5, 3.5]`。这避免了小股票池中一只异常涨跌停股票把均值/方差拉偏，从而独占 Softmax 权重。

### 2. 信号感知的逆波动风险预算

候选股票已经由因子或 LLM 信号筛选；配权阶段不推翻该信号，而是与逆波动权重混合：

```text
w_final = (1 - λ) × w_signal + λ × normalize(1 / σ20)
```

默认 `λ = 0.65`，可通过 `BacktestConfig.risk_parity_strength` 做消融：`0` 为原信号配权，`1` 为纯逆波动配权。系统同时输出每只股票的预期风险贡献：

```text
RC_i = w_i × σ_i / Σ(w_j × σ_j)
```

这比只展示“买了哪些股票”更完整：可以说明每个仓位承担的风险、组合是否集中，以及优化是否真的降低了波动代理。

## 长周期验证设置

- 数据：项目内确定性合成市场；不依赖实时接口或 LLM，保证两组比较使用完全相同的输入。
- 周期：4 个市场情景，每个情景 504 个交易日（约两年），共 4,032 个模拟交易日。
- 调仓：每 5 个交易日；6 个候选标的，最多 4 个持仓。
- 对照：`λ=0` 的信号权重基线 vs `λ=0.65` 的信号 + 逆波动风险预算。
- 复现：`./.venv/Scripts/python.exe -B scripts/evaluate_factor_walk_forward.py --days 504`

> 合成市场用于验证工程链路、风险预算行为和跨情景稳定性，不代表真实市场收益承诺。真实 A 股验证应使用带日期对齐的历史股票池快照，并进一步进行多窗口样本外检验。

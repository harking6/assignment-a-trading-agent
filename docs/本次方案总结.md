# 成员 B 工作汇报：经验记忆层优化

## 一、负责内容与完成情况

我负责项目中的金融相关算法研究与落地，重点解决记忆层中“历史样本是否可信、哪些经验更应被优先复用”的问题。本次工作没有改变原有的选股、风控和仓位决策主流程，而是在多智能体交易系统的经验学习闭环中补齐样本质量控制与召回排序能力。

本次已完成以下工作：

- 建立经验样本质量评分与门控机制，过滤信息不完整、成交不可执行或结果不可观测的低质量样本；
- 建立“质量 + 相似度 + 时效性 + 市场状态一致性”的经验召回排序方法；
- 将成交执行情况、收益结果和持有周期写回历史经验，形成可追溯的学习闭环；
- 增加回归测试、合成端到端验证和消融实验脚本，为后续比赛结果对比提供可复现实验框架。

## 二、原有问题与改进思路

原系统已经能够记录历史决策，并在新一轮交易时召回相似经验。但原有召回主要依据特征距离，存在三个问题：

1. 信息不完整的记录可能与完整记录一起参与决策，低质量样本会放大噪声；
2. 较早的市场经验与近期经验权重接近，无法适应市场状态随时间变化的特征；
3. 市场状态仅以“同类/非同类”作简单处理，且在特征距离并列时可能无法体现状态匹配的重要性。

因此，我将“相似经验”从单纯的距离排序，改为“可信、相似、近期、同状态”的综合排序。需要强调的是：样本质量不等于收益高低。亏损但记录完整、执行真实的案例同样是有价值的反例，不应被直接删除。

## 三、核心算法设计

对于每条历史经验，我计算综合召回分数：

```text
召回分数 = 质量分 × 相似度分 × 时效分 × 市场状态系数
```

其中：

- **质量分**：由特征完整度、成交执行情况、结果可观测性和决策链路完整度组成，权重分别为 40%、25%、20%、15%；
- **相似度分**：由当前市场特征与历史样本特征的标准化距离转换得到，距离越近，相似度越高；
- **时效分**：采用指数衰减，半衰期设置为 20 个交易日，使近期经验在其他条件相近时优先被召回；
- **市场状态系数**：市场状态一致时取 1，不一致时降为 0.45，避免跨行情模式的经验被过度迁移。

在门控阶段，质量分低于 0.65 的样本不参与正式经验注入；在完整方案中，还通过有效样本量（Neff）判断权重是否过度集中。当有效样本量不足 2 时，系统不向大模型注入该批经验，避免由单个历史案例主导当前判断。

同时，我加入了时间防泄漏约束：只有在当前决策时点之前已经完成结果观察的样本，才允许参与召回。这样可以避免回测中把未来收益错误地作为当前决策依据。

## 四、系统接入情况

| 模块 | 本次完成内容 |
| --- | --- |
| `agents/memory.py` | 将经验记录升级为可追溯结构，新增质量评分、时效衰减、市场状态加权、有效样本量计算及召回元数据。 |

改动后的经验学习链路为：

```text
交易决策 → 成交执行回填 → 收益结果回填 → 质量门控与相似经验召回 → 多智能体决策参考
```

## 六、后续实验安排与当前边界

我已准备好真实数据上的消融实验框架，实验包含四类代表性行情：春节反弹、1 月杀跌、震荡阴跌和 9·24 急涨。每类行情均按“历史预热区间 + 后续测试区间”划分，避免将测试期信息提前写入记忆库。

实验将对比五组设置：

| 组别 | 设置 |
| --- | --- |
| A | 不使用经验记忆 |
| B | 原有距离召回基线 |
| C | 仅启用质量门控 |
| D | 质量门控 + 时效偏置 |
| E | 完整方案：质量、相似度、时效性、市场状态与有效样本量保护 |

每组将进行多次独立运行，并输出收益、回撤、夏普率、胜率、换手率等指标的中位数及波动范围。当前本机尚未配置可调用的大模型 API 密钥和固定历史数据快照，因此我没有将在线数据的单次结果包装为比赛结论；待补齐运行条件后，可直接执行脚本生成正式对比数据。

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_memory_ablation.py --agent-mode llm --runs 5
```

## 七、汇报结论

本次工作将系统的历史经验从“按距离直接复用”升级为“先判断是否可信，再判断是否相似、是否足够新、是否处于相近市场状态”。这样既保留了负面经验的学习价值，也降低了低质量样本和过期样本对极端行情决策的干扰，为后续消融实验和比赛答辩提供了可解释、可验证的算法改进点。

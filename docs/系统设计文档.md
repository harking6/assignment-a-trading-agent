# 多标的 Top-Down 智能交易 Agent — 系统设计文档

## 1. 总览：这个 Agent 是什么

一个**规则 + LLM 耦合驱动**的多标的 A 股选股交易系统。输入全市场行情，输出绝对目标仓位。
核心管线：全市场股票池 → 大盘趋势判断 → 行业筛选 → 个股精选 → 权重分配 → 风控执行。

**一句话**：规则层负责"把能算的全算好"，LLM 层负责"对着算好的东西做判断"，约束层负责"不让 LLM 乱来"。

---

## 2. Agent 用了哪些能力

### 2.1 知识库（RAG）

| 来源 | 内容 | 怎么用 |
|---|---|---|
| **申万行业备注** | 每个一级行业的结构特征（如"电子对政策利率与全球半导体周期高度敏感"） | 选中行业后自动注入 LLM 提示词 |
| **炒股书籍摘录** | 4 本经典（趋势交易 / 板块轮动 / 风控纪律 / 市场情绪）的精华，Markdown 存放于 `data/knowledge/` | TF-IDF 词法匹配 → 与当前市场语境最相关的段落注入 |
| **搜索 RAG** | LangChain 检索链，从市场文档中搜相关上下文 | 为 LLM 提供信息来源和引用 |

→ **增强效果**：LLM 不是从零开始瞎猜，而是带着领域先验做判断。

### 2.2 交易记忆（经验数据库）

| 存储 | 格式 | 内容 |
|---|---|---|
| `data/agent_memory.jsonl` | JSONL，每行一条 | 市场 K 线特征向量 + 选中个股 + 行业 + 市场观 + 仓位 + **回填后的超额收益** |

工作流：
```
决策时 → 记录输入（K线态、选了什么）
下个再平衡日 → 回填结果（区间超额收益 active_return）
下次遇到类似 K 线态 → 召回历史相似场景 + 结果 → 拼接为"经验课程"注入 LLM
```

→ **增强效果**：Agent 越跑越聪明。第一次见某种 K 线态只能裸判，跑过 3 次以上就能参考历史成败。

### 2.3 情绪快照

`MultiSentimentFeed` 对候选股集合批量计算：
- **市场级**：广度（几成股票在 SMA20 上方）+ 平均收益 + 平均波动异常 → 市场情绪分
- **个股级**：日收益 + 量比 → 每只股的个体情绪信号

→ **增强效果**：LLM 拿到的不只是冷冰冰的价格，还有"市场现在是什么氛围"。

### 2.4 工具调用（LangChain Tools）

统一工具入口提供：
- 市场窗口（当前行情快照）
- 组合敞口（当前仓位、可用现金）
- 风险限制（最大仓位、回撤预算）

→ **增强效果**：LLM 知道自己有多少子弹、能打多大。

## 4. 五层耦合架构

系统分为五个独立层，每层职责清晰、互不越界：

```
┌──────────────────────────────────────────────────────┐
│                    ⑤ 约束层                           │
│          硬风控 · LLM 不可绕过 · 始终执行              │
│  ─────────────────────────────────────────────────── │
│  现金储备 ≥ 5%       单股 ≤ 25%                       │
│  最大持仓 ≤ 6 只      整手交易约束                     │
│  禁止无仓卖出         手续费 + 滑点检查                 │
│                                                       │
│  产出：最终可执行订单                                  │
└──────────────────────┬───────────────────────────────┘
                       ▲
┌──────────────────────┴───────────────────────────────┐
│                    ④ LLM 层                           │
│             语义合成 · 在线可选 · 挂了降级              │
│  ─────────────────────────────────────────────────── │
│  市场观 Agent    趋势评分 + K线 + 情绪 + 经验课程      │
│                  → bullish / neutral / bearish        │
│  行业 Agent      RS 排名 + 盈利代理 + 知识库上下文     │
│                  → 选出最优板块                        │
│  个股 Agent      动量 + 质量 + 情绪                    │
│                  → 候选股排序                          │
│  分配 Agent      前序决策 + 历史成败                   │
│                  → 权重建议                            │
│                                                       │
│  产出：建议 → 注入⑤                                   │
└──────────────────────┬───────────────────────────────┘
                       ▲
┌──────────────────────┴───────────────────────────────┐
│                    ③ 记忆层                           │
│             经验存储与召回 · 只读不写 LLM               │
│  ─────────────────────────────────────────────────── │
│  决策记忆      agent_memory.jsonl                     │
│               K线特征 + 决策 + 回填后的超额收益        │
│  经验召回      欧几里得距离 + 同机制偏置               │
│               ≥3条相似记录 → 拼接经验课程              │
│  知识库        申万行业备注（始终注入）                │
│               data/knowledge/*.md（TF-IDF 匹配）       │
│  回填          下个再平衡日 → 写入 active_return       │
│                                                       │
│  产出：文本 → 注入④                                   │
└──────────────────────┬───────────────────────────────┘
                       ▲
┌──────────────────────┴───────────────────────────────┐
│                    ② 规则层                           │
│               确定性特征工程 · 始终运行                 │

│  趋势评分      MA栈 0.30 + MACD 0.15 + volume_z       │
│                0.10 + 累计收益 0.25                   │
│  行业 RS       z(相对强度) + 0.5×z(盈利增长代理)      │
│  K线特征       [avg_RSI, avg_vol, breadth, dist_SMA] │
│  情绪快照      广度 + 平均收益 + 量比                  │
│                                                       │
│  产出：数字 → 注入③④                                 │
└──────────────────────┬───────────────────────────────┘
                       ▲
┌──────────────────────┴───────────────────────────────┐
│                    ① 工具层                           │
│             基础设施 · 为上层提供能力                  │
│  ─────────────────────────────────────────────────── │
│                                                       │
│  行情数据      akshare（腾讯/sina/申万三端点容灾）     │
│              全市场spot + 日线OHLCV + 申万行业成分     │
│                                                       │
│  技术指标      indicators.py                          │
│              RSI / MACD / ATR / SMA (5/20/60)         │
│              波动率 / 量比 / 收益率                    │
│                                                       │
│  情绪引擎      news.py → MultiSentimentFeed           │
│              市场级（广度+平均收益+波动异常）          │
│              个股级（日收益+量比）                     │
│                                                       │
│  基础知识      fundamentals.py → FundamentalsFeed     │

│              / risk_limit（LLM 可主动调用）             │

│  模拟券商      broker.py → SimulatedBroker            │
│              持仓管理 / 现金 / 手续费 / 滑点           │
│              平均成本 / 已实现盈亏 / 订单拒绝          │
│                                                       │
│  整手约束      sizing.py                              │
│              A股100股整手 + 取整                       │
│                                                       │
│  产出：所有上层依赖的原始数据和基础能力                 │
└──────────────────────────────────────────────────────┘
```

**数据流**：①工具层出数据 → ②规则层算特征 → ③记忆层出经验 → ④LLM 层做判断 → ⑤约束层保安全

**各层为什么独立**：

| 层 | 职责 | 特点 |
|---|---|---|
| ① 工具层 | 提供原始数据 + 基础能力 | 无状态，每次调用独立 |
| ② 规则层 | 把数据变成结构化特征 | 确定性，同样输入同样输出 |
| ③ 记忆层 | 跨时间积累经验 + 领域知识 | 有状态，越跑内容越多 |
| ④ LLM 层 | 对着特征和经验做语义判断 | 在线可选，挂了降级 |
| ⑤ 约束层 | 把建议变成安全订单 | 硬规则，LLM 不可绕过 |

## 6. 关键设计决策

### 6.1 小样本门控
经验注入要求 ≥ 3 条回填记录。1-2 条是噪音，可能在极端行情中反向误导 LLM。

### 6.2 同市场机制偏置
经验召回时，相同 market_view（bullish/neutral/bearish）的记录欧几里得距离 +0.5 偏置。
牛市里召回的经验应该也是牛市的，而非熊市的。

### 6.3 盈利增长代理
用 `avg_return_20d`（20 日平均收益）作为盈利增长预期的市场提前反映。
不依赖财报数据（财报季度更新、滞后严重），而是直接用量价反映市场共识。

### 6.4 综合趋势评分
不用简单的 ±5% 阈值判断牛熊，而是合成四维因子：MA 栈结构 + MACD 柱 + 成交量异常 + 累计收益。
多维度交叉验证，单因子假信号被稀释。

### 6.5 数据源容灾
- 基准 000300 裸代码 → `_BARE_INDEX_CODES` 白名单防误判
- eastmoney spot 无行业列 → 自动兜底为申万 `industry_map()`
- 基准加载失败 → synthetic 兜底（标注 `benchmark_error`）

## 7. 技术栈

| 层 | 技术 |
|---|---|
| 编排 | LangGraph（StateGraph + MemorySaver + 条件路由） |
| LLM 调用 | LangChain ChatOpenAI → deepseek-v4-flash |
| 行情数据 | akshare（腾讯/sina/申万三端点容灾） |
| 向量 & 检索 | TF-IDF 词法匹配 + 欧几里得距离 |
| 知识存储 | JSONL 交易记忆 + Markdown 知识库 |
| 回测引擎 | 事件驱动逐日推进 + 模拟券商（手续费/滑点） |
| 前端 | Flask + Vanilla JS |
| 测试 | unittest（28 个测试，覆盖合约/学习层/趋势/多LLM管线） |

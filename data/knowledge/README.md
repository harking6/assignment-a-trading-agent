# 炒股知识库书摘

本目录放置交易相关书籍的摘录/笔记（纯文本或 markdown），供 `MultiKnowledgeBase`
按行业/市场观召回，注入多标 LLM 的 sector/stock 决策 prompt。

文件命名建议：`<主题>.md`，内容尽量分段、带关键词（行业名、市场观、策略名），
便于词法检索命中。新增书摘直接丢文件到这里即可，无需改代码。

## 现有内容

- `趋势交易.md` — 《海龟交易法则》《以交易为生》趋势跟随要点
- `板块轮动.md` — 板块相对强度 / 领涨龙头 选股要点
- `风控纪律.md` — 仓位上限、止损、现金储备原则
- `市场情绪.md` — 贪婪/恐惧、广度、量能信号
